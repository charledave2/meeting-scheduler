# Release validation — 2026-11-10

Version 0.39.0 includes security hardening, image-loading performance improvements, responsive layout adjustments and forest-green theme updates.

The release workflow runs Android debug/release compilation and Android lint. The backend workflow builds and deploys the Cloudflare Worker using a reproducible dependency lockfile.

Device-level navigation benchmarks and full phone/tablet, split-screen, orientation and enlarged-font testing remain necessary. Build success does not certify universal compatibility or absolute security.
